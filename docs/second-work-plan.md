# Portfolio 02 delivery plan

The supplied 30-section production plan is preserved as the product direction. This repository starts with the first vertical slice and keeps the following order for the next iterations:

1. Verify the real local Gemma 4 API and model identifier.
2. Select and evaluate a Japanese embedding model before creating the immutable Vectorize index.
3. Replace the in-memory adapter with D1/R2 metadata and Vectorize vectors.
4. Add authenticated Cloudflare Tunnel/Access connectivity and deployment acceptance evidence.
5. Add browser acceptance, screenshots, README demo evidence, and portfolio listing.

Explicitly deferred from the first release: OCR, Word/Excel, Google Drive, SharePoint, Slack, MCP, agents, knowledge graphs, hybrid search, rerankers, billing, and complex authorization.
